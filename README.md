# Picker_File
Простой HTML файл для проведения кастомных ревизий и учёта

# Как работает

Скачиваем файл на смартфон или ТСД. Вносим данные с помощью клавиатуры или сканера штрихкодов.
Как внесли, скачиваем отчёт CSV или отправляем его сразу в мессенджер

Также, можно заранее создать файл для автосохранения, чтобы ничего не потерять. 

Файл для автосохранения, можно синхронизировать через Яндекс.Диск или Google.Drive чтобы сразу смотреть его на компьютере.
